# Форма роста

Фитнес-трекер с геймификацией: тренировки, прогресс, очки, достижения и рейтинг.
Конкурсное задание «Профессионалы 2026», компетенция «Веб-технологии».

## Стек

- Next.js 15.5 (App Router) + React 19 + TypeScript strict
- Tailwind CSS v4, дизайн-токены на CSS-переменных
- Motion-анимации пока нет: вся моушен-слой — CSS (transform/opacity), чтобы
  переходы не падали на занятом main-потоке во время навигации
- Sonner — тосты
- Zod — валидация форм
- Данные: мок-адаптер в `src/lib/api-client.ts` (модуль A). В модуле B тот же
  интерфейс будет ходить в REST API поверх SQLite (Drizzle).

## Запуск

```
npm install
npm run dev
```

Открыть http://localhost:3000 — редирект на `/dashboard`.

## Демо-доступ

Логин на `/login` принимает любой e-mail/пароль (валидация по формату),
кнопка «Войти в журнал» ведёт в приложение. Демо-аккаунт: Максим Орлов,
34 тренировки, серия 12 дней, 4 место в рейтинге.

## Экраны

- `/dashboard` — сводка недели: KPI, график объёма с переключателем периода,
  кольцо цели, донат групп мышц, достижения, топ рейтинга
- `/workouts` — журнал тренировок, клик по строке открывает карточку
- `/workouts/:id` — упражнение × подходы × вес, заметки, кнопки действий
- `/exercises` — каталог: живой поиск, фильтр по группе мышц, пустое состояние
- `/leaderboard` — рейтинг с переключением метрик (очки/тренировки/объём/серия)
- `/profile` — рекорды, история, достижения
- `/login`, `/register` — брендовый сплит-скрин, валидация форм

Каждый экран имеет loading-состояние (skeleton), empty — там, где возможно
(каталог). Кнопки, которые требуют бэкенда (создать/редактировать/удалить),
отзываются тостом и будут подключены в модуле B.
